# Social Metrics · 社媒采集插件

在桌面版 **Chrome 或 Microsoft Edge** 中导入账号表，采集 Instagram / YouTube 指定日期范围内的发布内容和公开指标，再导出 Excel / JSON。当前插件版本 **0.8.1**。Facebook 暂不支持，旧表中的对应行会提示跳过。

项目现在只维护浏览器插件及其测试，不需要 Python、PyCharm、独立调试浏览器或本地服务。使用说明见 [插件指南](extension/README.md)，实测清单见 [操作与验收步骤](操作与验收步骤.md)，版本变化见 [更新记录](CHANGELOG.md)。

## 安装

1. 下载或克隆仓库，保留解压后的文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载解压缩的扩展”，选择项目里的 **`extension`** 文件夹。该目录直接包含 `manifest.json`。
4. 从浏览器工具栏点击 **Social Metrics · 社媒采集**，打开工作台。
5. 采集 Instagram 前，在安装插件的同一浏览器用户配置中登录 Instagram，并保持标签页开启。采集 YouTube 时，在插件工作台填写自己的 YouTube Data API Key。

两种浏览器使用同一份目录，最低 Chromium 版本为 120。Edge 和 Chrome 的登录状态不互通，插件不会复制 Cookie。当前为本地加载方式，未发布到扩展商店。

### 从旧目录升级

0.5.0 将原来的 `edge-extension` 目录改名为 **`extension`**。先停止旧任务并导出需要保留的结果和诊断日志；更新代码后，到扩展管理页移除旧安装，再从新目录加载。不要只点击旧扩展的刷新按钮。路径变化可能导致扩展 ID 和本地存储变化，旧扩展的暂存结果不会自动迁移。加载后确认版本为 0.8.1，重新打开工作台、导入账号表和填写 YouTube Key。已经使用 `extension` 目录的用户，只需在导出结果后重新加载扩展，再关闭旧工作台并从图标重新打开。

## 使用

1. 选择 Instagram、YouTube 或两者混合，下载相应账号模板。
2. 在模板“账号清单”中每行填写一个主页链接，账号名和平台选填；保存并导入插件。文件不超过 10 MB，每轮最多 500 个账号。
3. 选择日期范围和时区，确认下方显示的起止日期及天数。
4. 点击“开始采集”，查看账号进度、页面操作次数和耗时。
5. 完成或停止后点击“下载 Excel 结果”。需要排查问题时，可复制或下载诊断日志。

0.7.0 使用深蓝色工作台：左侧配置可独立滚动，桌面窗口中的开始 / 停止按钮保持可见；右侧按“准备账号 → 读取内容 → 导出报表”显示当前阶段，并分别统计已读帖子、去重后的已处理账号和待核对账号。导出与运行记录独立展示，不渲染逐帖明细。进度到达 100% 不代表数据已查全，仍需检查待核对项。窄窗口改为上下布局，支持 320 / 390 像素宽度和键盘操作；样式、字体和图形使用本机资源，不新增远程依赖。

0.8.0 在工作台顶部增加 **界面风格**（精致科技 / 经典简洁）与 **颜色模式**（深色 / 浅色 / 跟随系统），两项可独立组合。默认保留上一版的精致科技深色界面；选择会自动记在本机，下次打开恢复。“跟随系统”会响应系统外观变化，明确选择深色或浅色时不受系统变化影响。切换即时生效，无需刷新，不改变采集设置、已有结果或正在运行的任务。

高级设置的采集方式、批次 / 页数、帖子详情上限和页面操作间隔旁提供 **i 说明按钮**。鼠标悬停或键盘聚焦可查看说明；点击可固定，再次点击、按 Escape 或点击外部可收起。采集过程中也可以查看，窄窗口会自动调整说明位置。

0.8.1 统一所有下拉框的收起与展开样式，随两种风格及明暗颜色变化，当前选项带勾选标记。支持鼠标与键盘选择，菜单会避开窗口边缘和配置区裁剪；已保存选择、动态标签页列表和采集时的禁用状态保持同步。

日期选择支持：

- **最近几天**：含所选时区的今天，1–366 天。
- **指定一天**：只采集所选日期。
- **按月份**：指定年月，自动使用当月 1 日至最后一天，包含闰年的 2 月 29 日。
- **按季度**：指定年份和季度；第一季度 1 月 1 日–3 月 31 日，第二季度 4 月 1 日–6 月 30 日，第三季度 7 月 1 日–9 月 30 日，第四季度 10 月 1 日–12 月 31 日。
- **自定义范围**：指定起止日期，包含首尾，可跨年，单次最多 366 天。

月份和季度保留完整日历范围，不会自动缩短到今天。涉及今天或未来日期时会提示该时段尚未结束，本次只能读取截至采集时已发布的内容。日期归属按所选时区判断；设置月份或季度不会自动增大主页批次和详情访问上限。

## 数据与限制

Instagram 正常打开主页和必要的帖子详情，复用页面 DOM、内嵌 JSON 和页面自身请求返回的数据。仅在字段不足时访问详情，默认间隔 3–5 秒；遇到登录验证、访问限制或 429 时停止该平台，不自动重试。YouTube 使用官方 Data API，需有效 Key 和可用配额。

Excel 包含“采集结果”“待人工核对”“本次运行信息”，记录日期模式、实际范围、时区和运行信息；原账号文件不被修改。隐藏指标保留“未公开或不可用”。Instagram 未查全时保留成功帖子及 `PAGE_INCOMPLETE`，不会误判为无发布。按季度查看历史内容可能需要增加读取上限，也会增加耗时。

界面风格、颜色模式、平台、日期范围、时区和高级设置自动保存在当前浏览器，下次打开恢复。YouTube Key 默认勾选“在本机记住 API Key”，填写后自动保存；取消勾选会删除已保存的密钥，但本页仍可使用当前输入；“清除已保存密钥”同时清空输入。配置使用本机扩展存储，不通过浏览器账号同步，Edge / Chrome 及不同用户配置各自独立。卸载扩展或清除数据会删除配置；账号文件需重新选择，不自动开始采集。

密钥不写入结果、会话恢复记录或诊断日志。诊断日志会过滤凭据、账号名和帖子正文，不自动上传。采集期间保持浏览器与工作台开启，结束后主动导出。

## 仓库内容与验证

- `extension/`：可直接安装的插件、用户指南及本地 Excel 组件许可证。
- `tests/extension-*.test.mjs`：日期、采集器、导出、错误和日志的离线单元测试。
- `tests/extension-browser-smoke.cjs`：Edge / Chrome 隔离浏览器集成测试。
- `tests/extension-preferences-browser.cjs`：配置与密钥的重载、浏览器重启及清除测试。
- `tests/extension-ui-browser.cjs`：界面风格 / 颜色模式、统一下拉框、帮助说明、状态与统计、桌面固定操作区、窄屏布局和键盘焦点测试。
- `操作与验收步骤.md`、`CHANGELOG.md`：操作清单和版本记录。

旧 Python 源码、安装脚本、模板生成器、独立浏览器启动器、旧接口实现和相应测试已移除。已有本机配置、缓存、账号表和导出文件保留为忽略项，不属于插件依赖，也不随代码提交。

开发检查使用 Node.js，安装插件本身无需 Node.js：

```bash
node --test tests/extension-*.test.mjs
```

浏览器测试另外需要 Playwright、本机浏览器和 OpenSSL，运行方法见 [开发者离线检查](extension/README.md#9-开发者离线检查)。测试使用本机模拟数据，不消耗真实平台配额。离线通过不代表真实账号的全部历史帖子都可读取，仍应核对实际导出结果。
